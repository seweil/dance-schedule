Claude Code inside WebStorm

Keybindings can shift slightly between Claude Code versions. If anything here doesn't match what you see, type /help inside Claude Code for the current list.

05

Managing several subtasks at once

  • A background agent or fork doesn't block the main conversation — keep typing, ask questions, or start another task while it runs.
  • When a background task finishes, a notification lands in the conversation on its own — no need to poll or ask “is it done yet?”
  • Check what's actually running any time with /tasks, or expand a subagent's own inline output with ⌃O, rather than guessing.
  • Asked too early, the honest answer is always “still running” — there's no way to peek at partial results before that notification.
  • A subtask's detailed work stays out of the main conversation by design — you get a synthesized summary on completion, not a raw transcript.
  • If something runs away or you no longer need it, ⌃X ⌃K stops every background subagent in the session at once.
  • For two genuinely unrelated things at once, a second WebStorm terminal tab running its own claude process is cleaner than one conversation juggling both.
  • Avoid rapid-fire Esc while waiting on a background subtask — it stops the main session, not the work already dispatched.
